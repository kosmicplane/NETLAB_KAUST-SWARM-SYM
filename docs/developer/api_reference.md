# API reference

The machine-readable contract is `openapi/netlab-openapi.yaml`.

Principal endpoints include `/api/health`, `/api/status`, `/api/config`, `/api/config/validate`, `/api/apply`, `/api/topology/apply`, `/api/swarm/apply`, `/api/antennas/apply`, `/api/world/apply`, `/api/failures/apply`, `/api/telemetry`, `/api/stream`, `/api/synchronization`, `/api/jobs`, `/api/plugins`, `/api/scenarios`, `/api/evidence`, and `/api/research/*`.
