# Metrics catalog

Communication metrics include packet states, PDR, packet advancement, throughput, goodput, capacity, delay, jitter, queues, SNR/SINR, received power, path loss, spectral efficiency, margins, LoS ratio, outage, utilization, Jain fairness, handover, and Age of Information.

Topology metrics include components, hop count, path stretch, churn, diameter, degree, density, articulation points, bridges, disjoint paths, algebraic connectivity, path diversity, redundancy, branch/swarm availability, continuity, and failed-node tolerance.

Control, energy, recovery, synchronization, and platform metrics are defined with units, source, fidelity, model version, timestamp, freshness, quality, and uncertainty metadata.
