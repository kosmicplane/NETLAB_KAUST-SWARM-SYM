# Declared fidelity boundaries

Pegasus is intentionally outside the required release path. F3 geometry-aware results require a working Sionna RT environment and compatible scene materials. Detailed NR/MAC/RLC behavior requires an external protocol adapter. F5 requires PX4 SITL. F6 requires experiment-specific hardware. The UI exposes these profiles only with explicit availability and provenance; unavailable models cannot silently fall back without a recorded policy.
